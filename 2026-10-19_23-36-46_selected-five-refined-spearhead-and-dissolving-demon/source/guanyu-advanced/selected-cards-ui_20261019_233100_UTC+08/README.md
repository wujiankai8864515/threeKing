# 选定五卡：精致长枪头 UI 修订
时间：2026-10-19 23:31 UTC+08

上一版把低清旧图标放大造成失真，已被用户否决。本轮通过 imagegen 重新生成独立1254×1254透明锻钢长枪头源，中心脊、两侧刃面、套筒与短杆清楚。原始生成参数见 actual-imagegen-args.json。

按alpha>16的可见边界裁去透明留白，再等比缩至130px高；没有放大旧素材、横向拉伸或加黑底。render.py 保持原有圆章中心与所有其他UI锚点，render_config.py 使用已选03象牙金釉·御铸六星框，五星使用原钻石标准框。

五星机甲、五星传承、神05、六星机甲08均冻结原图。QA-four.json 与上一批逐像素比对，图标区域之外变化为0；完整卡生成时再次验证未覆盖插画像素改变为0。六机甲使用主动龙御天穹、被动镇岳/逆鳞/天诛，仅命名升级，防御受击蓄能反击机制不改。

魔卡最终使用 demon02-dissolve-safearea-source.png：人形崩解与黑龙成魔，城匾移至技能栏下方安全区。实际成卡目检麦城二字完整可见。history-covered-city仅遮匾旧稿，非交付。manifest.json列出最终五张完整卡及对应源与UI。
