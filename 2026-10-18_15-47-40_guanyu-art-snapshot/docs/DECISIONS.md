## 视觉主轴
以《三国演义》的传记顺序和地面生活空间为根，以原创神话、漫画动态表达人物、龙与战斗。市井、桃林、黄巾战场、中国关隘和山中古道应可辨认；不能将主要场景重新变成漂浮天宫。龙与神力可以超现实。卖豆是民间改编元素，不应伪称演义原文。

## 四阶
1. 黑铁 / 一星：卖豆市井中的潜龙，未起势的英雄。
2. 青铜 / 二星：黄巾初征，初入战场，较朴素装备。
3. 白银 / 三星：关前扬威，斩华雄的成名阶段。
4. 黄金 / 四星：赤兔过关寻兄，力量与动态最强。

主角面孔、胡须、身体身份跨阶一致，装备与场景随阶段发展。当前卡片文件名中部分仍有旧阶段别名（如桃园初征、天降龙斩、神路寻兄），不要仅凭文件名推断最新语义；显示含义以本页为准。

## UI 与源图
四种通用材质框与星级冻结。框本体、独立星级 UI、纯插画、合成预览分别保留。角色名与阵营应运行时显示，通用框内留空，不烘焙不可复用的文字。当前美术合成脚本不是运行时 UI 或游戏系统实现。

## 传记
选择最有代表性的经典瞬间，不用铺垫事件替代核心画面；铺垫可用第一人称文案表达。桃林结义新版已批准。过关寻兄用真实古道与关隘支撑神话战斗，当前地面版待审。
