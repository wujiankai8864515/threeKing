# 六星机甲关羽 · 立体宝物框唯一候选

本轮仅制作一个设计并合成一张完整卡。五星最新通透钻石框未修改。

## 结构与材质
铂金精工、深墨青珐琅、少量深玉宝石。双龙冠饰、独立层叠护角、精细浮雕与两枚悬浮纹章相呼应。禁止赤金橙红、紫晶与密集碎光。

## 布局与像素
继续使用最新标准 renderer，原核心UI画布1190×1786、08插画1024×1536按1:1放置、姓名/蜀/LV/等级/封侯/被动/枪图标动态锚点均保持。为冠饰与外侧构件增加透明外边距，最终画布1310×1966，核心坐标整体偏移(60,140)，不缩放插画、不重画人物。生成框的姓名板原本偏低，compose.py在不改变动态文字锚点的前提下，局部重置姓名板并保护左右圆章/菱章。

生成原始框真实分辨率1024×1536，透明RGBA，适配最终框尺寸；不宣称原生4K。实际工具参数和参考在actual-args.json与layout-reference-neutral.png中。仅一次框生成，未生成多版卡。

主动龙御天穹、被动镇岳/逆鳞/天诛、封侯均保留配置。主动名不额外添新栏，以维持原标准信息布局。

## 可复现
运行python3 compose.py可复现完整卡与核心合成。render.py、独立UI层、真实源图与生成框、配置、源映射、QA与SHA齐全。完整卡是六星机甲关羽-立体宝物框.png；独立完整透明框为frame-6star-expanded.png。card目录的核心裁切卡仅为合成中间产物，不是第二款候选。
